ТРЕНАЖЁР ДЕЖУРНОГО ПО СТАНЦИИ (ДСП): АКЖТ + путевой пост, Алгабас, программа преподавателя
=========================================================================================

ГДЕ ЧТО (папки переименованы 28.10.2026)

  готовая_программа\        — ЗАПУСКАТЬ ОТСЮДА: собранные программы, прошивки макета, инструкции
      АКЖТ\Station.exe           пульт станции АКЖТ и путевого поста (+ светофоры.txt — карта ламп макета, Arduino\ — прошивка)
      Алгабас\Algabas.exe        пульт станции Алгабас (+ датчики.txt, Arduino\ — скетч)
      Преподаватель\Teacher.exe  программа преподавателя (данные — папка данные)
      Сервер\PromServer.exe      сервер связи (Teacher.exe запускает его сам)
      Редактор станций\StationEditor.exe  редактор схем «кубиками» (C#), схемы сохраняет в .station.json (папка Станции)
      Инструкции\index.html      инструкции студента, преподавателя, программиста (ru / kk / en)

  Исходники\                — исходный код (C#, .NET 8; сервер — Go)
      АКЖТ\            проект Station (Station.sln), CHANGES.md — журнал изменений, build_exe.bat, Arduino\ — прошивки
      Алгабас\         проект Algabas (Algabas.sln), CHANGES.md, build_exe.bat
      Преподаватель\   проект Teacher, build_exe.bat
      Сервер\          PromServer (Go), build_exe.bat
      Редактор станций\  макет редактора схем «кубиками» (HTML/JS): открыть index.html, см. README.txt
      Редактор станций CSharp\  тот же редактор на C# (StationEditor.sln), build_exe.bat, см. README.txt
      Редактор_05_11\  C#-редактор с правками по info.txt (05.11.2026): амперметр, показания светофоров, маршрутные,
                       предупредительные, повторительные, заградительные, прикрытия, вокзал, часовая башня; см. README.txt
                       (build_exe.bat собирает в готовая_программа\Редактор_05_11)

  Инструменты\              — тесты (PanelTest, JournalsTest, ShuntTest, LampMapTest, UiModesTest…), сквозные тесты e2e_*.ps1,
                              перевод интерфейса (i18n), снимки окон для инструкций (DocShots)
  Документы\                — ТЗ, ответы на вопросы, план этапов, PDF тренажёра-образца, таблица распиновки светофоров
  Архив\                    — старое: Python-версия, старые копии исходников АКЖТ, остатки GitHub-репозитория AKZHT-station
  собрать_всё.bat           — собрать все программы в готовая_программа

РЕЖИМЫ ИНТЕРФЕЙСА (кнопка «Параметры» вверху окна станции, АКЖТ и Алгабас)

  Инженерный  — всё: наладка макета, «Лампы по одной», порт Arduino, список занятости участков
  Учебный     — для занятий: без наладочных панелей
  Рабочий     — как АРМ ДСП станции Медеу: работа с настоящим макетом, без имитации поездов
  Павлодарский — как тренажёр «Енисей» Павлодарского колледжа: серая схема и кнопочный пульт (пробный)
  Любую панель можно показать или скрыть галочкой там же.

Подробно для программиста: готовая_программа\Инструкции\programmer_ru.html
