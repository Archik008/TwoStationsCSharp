### Что важно этапу 4 и 7 (чтобы не сломать)
- **Категория поезда (этап 4).** Сейчас категория есть только в расписании (`SchedTrain.Category`), у `VirtualTrain` её нет.
  Когда добавишь категорию в `VirtualTrain`: в `Schedule.Spawn` есть `// TODO этап 4` — присвой `v.Category = t.Category`;
  в `Schedule.HoldReason` и `MinDwell` можно брать категорию у поезда, а не из расписания.
- **«Сократить стоянку» (радиосвязь, этап 4).** Стоянку держит `Schedule.HoldReason`. Дай поезду флаг (например
  `VirtualTrain.ShortStop`) и проверь его в `HoldReason` первым — тогда приказ отпустит поезд.
- **Физический поезд на макете** не `VirtualTrain`, номера у него нет → на ГИД не попадает. Если этап 4 даст номер участку
  («поезд = занятость с номером»), добавь его в `Schedule.Observe` (там обход `sim.Trains`).
- **ДУ-2/ДУ-3 (этап 4)** удобно сверять с `Schedule.Events` (факт прибытия/отправления, путь) — не считай факт заново.
- **Номер поезда** — ключ связи расписания, ГИД и оборота. Не меняй номер при передаче соседу (`DispatchMirror` и так передаёт его).
- Поезд от соседа: если сосед на связи — его передаёт сосед; если нет — `Schedule` выпускает его на границе сам
  (`AddBoundary`). Если добавишь новые входы на схему — регистрируй их в `Model/ScheduleSetup.cs`.
- Скорость поездов на уроке — `LessonTask.TrainStepSec` (12 с для расписания). Если этап 4 меняет скорость (предупреждения,
  «окна») — умножай `StepSeconds`, а не перезаписывай: `Schedule.End()` возвращает сохранённое значение.
- Протокол: `t_session.lesson.schedule`, `s_train_event {ev{number,station,kind,clock,track}}`, `s_result.trains`, `s_result.scheduleName`.

## 3. Этап 8 — языки (ru / kk / en)

### Как устроено (главное правило)
**Строки в коде остаются русскими — это ключи перевода** (как gettext). Переводится то, что показывается.
Поэтому код этапов 4 и 7 можно писать по-русски, как раньше, и сливать без конфликтов; перевод новых строк добавляется потом в словарь.

| Файл | Что |
|---|---|
| `Core/Lang.cs` (общий, + «Преподаватель» ссылкой) | `L.T(текст)`, `L.F(формат, …)`, `L.Html(html)`, `L.Set(код)`, `L.Current`, `L.Changed`. Поиск перевода: точный → шаблон с `{0}` (содержимое дырок переводится тоже) → приставки «08:01:05  », «[Занятие] » → многострочный → по разделителям → куски |
| `Ui/LangUi.cs` (общий, + «Преподаватель») | Окна переводятся **сами**: перехват показа окна и меню (`WM_SHOWWINDOW`), `MessageBox` (`WM_INITDIALOG`), обход раз в секунду, `TextChanged` → перевод до отрисовки, `Format`/`CellFormatting` для списков и таблиц, `ToolTip` из полей окон, `TranslateProperties(type)` для `PropertyGrid`, `Selector()` — выбор языка |
| `Lang/Strings.kk.json`, `Lang/Strings.en.json` (в АКЖТ и Алгабасе; «Преподаватель» берёт из АКЖТ) | Словари. **Руками не править** — генерируются |
| `tools/i18n/strings.tsv` | **Источник перевода**: русский ⇥ казахский ⇥ английский (`\n` внутри текста) |
| `tools/i18n/skip.txt` | Строки, которые переводить не нужно (части склеек, HTML-разметка, имена файлов, фамилии). Комментарии — `##` |
| `tools/i18n/check.py`, `extract.py` | Поиск непереведённых строк в коде, сборка словарей |
| `tools/i18n/ПРОВЕРИТЬ_КАЗАХСКИЙ.md` | Глоссарий терминов для проверки носителем |
| `tools/LangTest` | Тест перевода и снимки окон |

### Как добавлять новые строки (этапы 4, 7 и дальше)
1. Пиши интерфейс по-русски, как обычно. Окна, кнопки, меню, таблицы, `MessageBox`, журнал, отчёты переведутся сами,
   **если строка есть в словаре**.
2. `python tools\i18n\check.py` — покажет новые русские строки без перевода. `python tools\i18n\check.py --todo новое.tsv` — выпишет их в файл
   (третий и второй столбцы пустые): дописать казахский и английский, перенести строки в `tools\i18n\strings.tsv`
   (или ненужные — в `skip.txt`).
3. `python tools\i18n\check.py --build` → словари в обе станции → пересобрать программы.
4. `dotnet run --project tools\LangTest` — ключи без «{0}» в результате, примеры журнала.

### Где перевод НЕ сработает сам — делать явно
- **Своё рисование** (`DrawString`, `TextRenderer.DrawText`) — оборачивай: `g.DrawString(L.T(текст), …)`.
- **HTML, который пишешь не через `Reports.Open`** — перед записью в файл `L.Html(html)`. Через `Reports.Open` — уже переводится.
- **Логика по тексту подписи** (`if (btn.Text == "Вход")`) сломается: подпись уже переведена. Храни состояние в поле / `Tag`.
  (Шаблон `if (c.Text != text) c.Text = text;` — безопасен, просто чуть больше перерисовок.)
- **Не клади переведённое в данные и протокол**: в `s_result`, журналы, JSON — только русский (ключ). Переводится при показе.
- Элемент, который переводить нельзя (ввод пользователя в `Label`, названия языков) — `Tag = "nolang"`.
  `TextBox`, `NumericUpDown`, `DateTimePicker`, значения ячеек и пунктов списков не меняются никогда — только показ.
- Склейка `"Студент: " + имя` переводится по кускам; лучше писать целым шаблоном `$"Студент: {имя}"` — тогда ключ «Студент: {0}».
- Шаблон, где слов меньше двух букв (`"{0} с"`), переводчик не берёт — так задумано (совпадал бы со всем подряд).
- `PropertyGrid` нового класса — `LangUi.TranslateProperties(typeof(Класс))` один раз при запуске.

### Не переводятся (так решено)
Названия станций и объектов схемы (АКЖТ, Алгабас, Ч, Н1, М2, НП, 2-3СП…), аббревиатуры (ДСП, ДНЦ, ШН, ДУ-46, ОС/ОП/ОМ),
фамилии работников, всё, что ввёл преподаватель (ФИО, названия уроков и расписаний, описание расписания).
Учебные уроки и расписания «по умолчанию» переводятся, пока их текст не изменён (ключ — русский текст из кода).
