## 2. Отправная точка и git

- В папке `arnur` заведён git. Первый коммит — **«Этапы 1–3»**. Следом в `main` уже лежат большой экран ученика и **этап 6**
  (коммит «Этап 6: функции пульта ДСП…»). Начинай с того коммита `main`, который пришёл к тебе в папке — `git log` покажет.
  Заказчик переносит тебе папку `arnur` **целиком вместе со скрытой папкой `.git`** (exe в `готовая_программа` в git не входят — собери сам).
- Если этап 6 у тебя уже есть: `Interlocking` теперь `partial`, логика пульта — в `Core/Panel.cs`, кнопки — `Ui/PanelUi.cs`
  (колонка «Пульт ДСП»), у стрелки есть `ShownPlus` (положение на пульте: у стрелки на макете — макета). В зависимостях
  проверяй положение стрелки через `ShownPlus`, а поезд едет по `Plus`.
- Работай в ветке `stage4-5`: `git switch -c stage4-5`. Коммит после каждого законченного куска (минимум — после этапа 4 и после этапа 5),
  сообщение по-русски: «Этап 4: журналы ДУ-2/47/58/60», и т.п.
- **Нельзя**: `rebase`, `push --force`, переименовывать или переносить существующие файлы и папки, переформатировать чужой код,
  менять концы строк. В `.gitattributes` стоит `* -text` — git файлы не трогает. Новые bat — CRLF (см. «грабли» в плане).
- `Station_AKZH-main/.git_github` — это бывший git репозитория GitHub `AKZHT-station` заказчика (переименован, чтобы общий git видел код АКЖТ).
  Не трогай.
- В `ПЛАН_ЭТАПОВ_3-8.md` пути вида `C:\Users\user\Desktop\arnur` — это твой ПК, всё внутри `arnur` относительное.

### Как сдать работу на слияние
На твоём ПК, когда этапы 4–5 готовы и закоммичены:
```
git bundle create этапы4-5.bundle stage4-5
```
Заказчик приносит файл `этапы4-5.bundle` на ПК 09091, там: `git fetch этапы4-5.bundle stage4-5:stage4-5` и `git merge stage4-5`.
Слияние и конфликты разбирает Claude на ПК 09091. Чтобы конфликтов было мало — правила ниже.

## 3. Правила, чтобы правки слились

1. **Новое — в новых файлах.** Окна журналов, бланков, расписания, ГИД, радиосвязи — отдельными файлами
   (например `Ui/JournalWindow.cs`, `Ui/BlanksUi.cs`, `Core/Schedule.cs`, `Core/Journals.cs`, `Teacher/GidTab.cs`).
   Общие файлы ядра — как и раньше: правишь в АКЖТ, копируешь в Алгабас.
2. **В общих файлах — маленькие вставки** с пометкой `// [ДОБАВЛЕНО <дата>, этап 4]`, без перестановки соседнего кода.
3. **Где я (этап 6) буду работать много — туда заходи по минимуму:**
   - `Core/Interlocking.cs` — отмена маршрута с выдержкой (Е1), ИР (Е2), замыкание стрелок (Е4), колпачки (Е5), курбель (Е6),
     выключение стрелки из централизации и «макет» (Е7), автодействие (Е8), ключ-жезл (Е9), переезд (Е10), взрез (Е11), раздельное управление (Е14).
     Если тебе нужно новое условие для маршрута (например «окно» на участке — маршрут не задаётся), добавь **одну строку** в `CheckRoute`
     через новое поле в `Core/Model.cs`, логику держи в своём файле.
   - `SchemePanel.cs` (оба): меню **стрелки и светофора** — мои. Меню **поезда** (`TrainMenu`: «Номер и индекс…», «Вызвать по радиосвязи»)
     и **участка** (`SectionMenu`: «Предупреждение…», «Окно…») — твои. Пункты добавляй в конец меню перед `return m`.
   - `Ui/StationPane.cs` (АКЖТ) и `Ui/StationForm.cs` (Алгабас): колонка «Стрелки, направление, пригласительный» (`ctlCol`) — моя;
     колонка «Имитация» (`simCol`) и верхняя полоса — твои (кнопки «Журналы…», «Бланки…», «Расписание…» лучше одной кнопкой с меню).
   - `Ui/TrainingUi.cs` — снимок экрана и ввод преподавателя (`TrainingInput`) — мои (меняю под большое окно экрана).
   - `Teacher/ScreenView.cs`, экран станции в `Teacher/TeacherForm.cs` — мои. Вкладки «ГИД», «Расписание» — новыми файлами, в `TeacherForm` одна строка `tabs.TabPages.Add(...)`.
4. **Где будешь работать ты, а я — по минимуму:** `Core/TrainSim.cs` (категория, длина, скорость, приказы, предупреждения),
   `Core/Training.cs` (подсчёт по расписанию, `s_train_event`, журналы в `s_result`), `Teacher/Reports.cs`.
   Мне в `TrainSim.cs` нужно только: взрез стрелки (Е11 — поезд вступает на стрелку не по ходу) и ключ-жезл (Е9) — короткие вставки в `Advance`.
5. **Протокол.** Новые сообщения — по схеме `t_*` (преподаватель → станция) / `s_*` (станция → преподаватель), список — в шапке `Core/Training.cs`.
