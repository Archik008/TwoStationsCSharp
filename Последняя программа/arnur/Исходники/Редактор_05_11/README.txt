ЧТО НОВОГО (11.11.2026) — НУМЕРАЦИЯ ПО ПРАВИЛАМ (Model\Numbering.cs)
  Источники: ВСН 56-78 «Инструкция по проектированию станций и узлов», прил. 2 «Правила нумерации путей и стрелок»;
  РУ-30-80 «Указания по применению светофорной сигнализации», листы 89–90.
  Свойства станции (ничего не выбрано → «Свойства»), раздел «Нумерация (ВСН 56-78)»:
    «Чётные поезда идут вправо → / влево ←» — от этого зависит всё остальное (в файле — поле even: "R" / "L");
    «Боковые пути»: по чётности (чётные — со стороны чётного главного) или подряд от вокзала (малые станции);
    «Номера при рисовании» — новая стрелка сразу получает номер по правилам; у кисти «Участок»
    пункт «+ путь (номер по правилам)» — нарисованный мазком путь сам получает номер (IП, 3П, 4П…);
    «Перенумеровать всё по правилам» (и кнопка «Нумерация» вверху) — пути и стрелки заново; Ctrl+Z — отменить.
  Правила:
    главные пути — I (нечётный), II (чётный); главный — тот, по которому прямо можно выехать за обе горловины;
    движение правостороннее: нечётный главный — справа по ходу нечётного поезда (лист 89);
    боковые — со следующего номера: со стороны нечётного главного 3, 5, 7…, со стороны чётного 4, 6… (на однопутке 2, 4…);
    ОСЬ СТАНЦИИ — граница чётной и нечётной сторон: ось пассажирского здания (объект «Вокзал»), без него — середина
    между крайними стрелками; стрелки со стороны прибытия чётных поездов — чётные, нечётных — нечётные, от входа к оси,
    стрелки съезда — подряд (6/8);
    СВЕТОФОРЫ нумерация НЕ трогает (11.11.2026 откачено по просьбе Мади): имена светофоров — как раньше
    («→» Ч, «←» Н, подсказка редактора), кнопка «Нумерация» их не переименовывает.
  Проверено (модель): примеры «Алгабас», «Разъезд», «Разъезд с переездом» при чётных → и ←, тестовая двухпутная станция
  (I / II, 3П / 4П) — номера по правилам, маршрутов столько же, ошибок «Проверки» нет.
  Не проверено: вживую мышью.

ЧТО НОВОГО (05.11.2026, по info.txt)
1. Амперметр на табло (клавиша 8) — ток перевода стрелок. В «Испытании» стрелки переводятся приводом по очереди:
   пусковой бросок до 3,6 А, рабочий ток ~1,8 А около 3,2 с, пока стрелка идёт — у неё нет контроля (оба направления
   с разрывом), светофор маршрута открывается, только когда стрелки дошли.
   Препятствие (Shift+ПКМ по стрелке или галочка «стр. N» на вкладке «Маршруты»): ток фрикции ~2,4 А, через 7 с привод
   отключается, стрелка остаётся без контроля (мигает красная метка). Щелчок по ней — вернуть в прежнее положение.
   Цифры типовые для привода с двигателем МСП: в пособии (lokomo.ru) сказано только, что амперметр показывает ток
   перевода стрелок. Поменять — константы в Model\SwitchDrive.cs.
2. Основные светофоры: в «Испытании» горят настоящие показания (Model\Aspects.cs):
   входной — красный / жёлтый / зелёный / два жёлтых / два жёлтых с верхним мигающим;
   выходной и маршрутный — красный / жёлтый / зелёный / лунно-белый; маневровый — синий / лунно-белый;
   проходной — сам: красный (впереди занято), жёлтый, жёлтый мигающий (впереди входной на боковой путь), зелёный.
   Новые виды: маршрутный (НМ1 / ЧМ1), предупредительный (П + имя основного, две черты на мачте):
   зелёный / жёлтый / жёлтый мигающий, перед заградительным — жёлтый, когда тот красный; прикрытия (Пр1): красный,
   зелёный по щелчку, если впереди свободно.
3. Заградительный (З1, мачта в чёрно-белые полосы): нормально не горит, красный — когда переезд впереди занят
   или по щелчку в «Испытании». (Инструкция по сигнализации, гл. 2.8.)
4. Повторительный (Пв + имя выходного, одна черта на мачте): зелёный, когда выходной / маршрутный впереди открыт,
   иначе не горит — и тогда сигнального значения не имеет. (Гл. 2.9.)
5. Вокзал (клавиша 9) — пассажирское здание со своим названием; часовая башня (клавиша 0) — идёт по времени
   компьютера, секундную стрелку можно выключить. Выбор / перенос — инструментом «Выбор», название и размер — «Свойства».
Пример со всем новым: «Пример… → Разъезд с переездом (новые элементы)».

5. Повторительный — тоже ромб («фоновые щиты повторительных и заградительных светофоров имеют форму ромба»).
6. Подсказка имени нового светофора (Core.SuggestSignalName; имена в готовых схемах не меняются):
   выходной — буква направления + номер пути из участка клетки: 3П → Н3, IIП → ЧII, 2АП → Н2А;
   маршрутный — то же + «М»: ЧМII, НМ5А; прикрытия — буква + «П» + номер пути: НП1 (было Пр1);
   повторительный — «П» + имя основного: ПЧ1, ПЧМ2А (было ПвЧ1);
   маневровый — нечётные номера в горловине входного Н…, чётные — в горловине входного Ч… (по ближайшему входному;
   если входных нет — по направлению, как раньше).
7. Карликовые светофоры рисуются без мачты (короткое основание «|» у ламп): выходной / маршрутный с бокового пути
   и маневровый. Маневровый на тупике / вытяжке (участок …Т, ВТ…) — мачтовый (выход из нецентрализованной зоны).

ДОБАВЛЕНО 09.11.2026 — по ГОСТ 2.749-84 «Элементы и устройства ЖАТ» (https://files.stroyinf.ru/Data1/7/7197/index.htm), табл. 6
8. Два вида огней светофоров: кнопка «Огни по ГОСТ» на верхней панели или клавиша G.
   Выключена — огни в цвете, как раньше. Включена — графические знаки ГОСТ (как на чертежах РУ-30-80):
     красный — залитый круг; зелёный — пустой круг; жёлтый — заштрихованный круг;
     лунно-белый — круг с меньшим кругом внутри; синий — круг с залитым меньшим кругом внутри;
     мигающий — четыре коротких луча от круга (знак «редкое мигание»).
   Горящий огонь — чёрным по светлому, негорящий — бледно (видно, какая это лампа головки).
   Ромбы заградительного и повторительного заполняются так же (табл. 5, п. 7, 9).
   В этом виде показываются ВСЕ лампы головки (Model\Aspects.cs, FullHead), от мачты наружу:
     входной — пригласительный (отдельно, с отступом), жёлтый, красный, зелёный, жёлтый;
     выходной / маршрутный главного пути — лунно-белый, жёлтый, красный, зелёный, жёлтый; бокового — лунно-белый, красный, зелёный, жёлтый;
     проходной — красный, зелёный, жёлтый; предупредительный — зелёный, жёлтый; маневровый — синий, лунно-белый;
     прикрытия — красный, зелёный; заградительный, повторительный, предупредительный к заградительному — один ромб.
   Лампы вплотную друг к другу. Раскладка — как цельные светофоры на чертежах РУ-30-80:
     мачтовый — знак мачты «⊢», ножка и огни в ряд вдоль пути: «1 ⊢●○⊘», «Н1 ⊢◎⊘●○⊘», «◆—⊣З» (стр. 9, 49);
       у входного пригласительный отделён чёрточкой: «Н ⊢◎-⊘●○⊘» (стр. 9, 49); черт на мачте в этом виде нет;
     карликовый — огни сразу у основания «|», без ножки: 1–3 огня в ряд («НД |○○» стр. 9, «М1 |◎◎», «Нд |◎●⊘» стр. 49);
       4 огня — квадратом 2×2 (как Н3 на стр. 9: у пути красный и зелёный, дальше лунно-белый и жёлтый);
       5 огней — три у основания, два дальше.
   Вид «в цвете» не изменился.
   Код — Ui\Renderer.cs (GostLamps, DrawGostLamp), кнопка — Ui\MainForm.cs.
10. [ДОБАВЛЕНО 09.11.2026] Связь станций: у каждого светофора есть id (в «Свойствах», под строкой светофора).
   Новый светофор получает следующий номер сам (наибольший на схеме + 1), номер можно поменять.
   Старые файлы без id при открытии получают номера по порядку. «Проверка» ругается на повтор id.
   Галочка «только чтение (с другой станции)» — у любого вида светофора: показание задаёт другая станция по сети
   (как RailSignal.Remote / DispatchMirror в программах АКЖТ и Алгабаса). У такого светофора маршрутов нет,
   в «Испытании» он погашен (связи в редакторе нет — как у станций без данных от соседа), у имени значок «↔».
   В JSON: sigs: [{ …, "id": 5, "ro": true }]. «Экспорт в C#» пишет id всех светофоров и строки для списка
   mirror в DispatchMirror: ("5", CH1) — сетевое имя светофора = его id.
11. [ДОБАВЛЕНО 09.11.2026] Светофор всегда лежит параллельно пути, как на схемах РУ-30-80 (Ч22 на наклонном пути, стр. 89):
   на наклонном пути (и у наклонного конца изгиба) он повёрнут на 45° вместе с огнями, мачтой и подписью,
   по-прежнему справа по ходу движения. На изгибе угол берётся с того конца клетки, где стоит светофор.
   Работает в обоих видах огней; выбор мышью учитывает поворот. Код — Ui\Renderer.cs (SigAngle, SigGeom.Angle, Hit).
12. [ДОБАВЛЕНО 09.11.2026] «Проверка» предупреждает, если поездной маршрут проходит мимо другого поездного светофора
   того же направления (входного, выходного, маршрутного) и идёт дальше — обычно это значит, что участку перед ним
   не задан тип «путь» (участок назван просто «3», а не «3П»), и маршрут приёма уходит сквозь станцию на перегон.
   Выходной в конце пути приёма предупреждения не вызывает. Щелчок по строке — показать светофор. Код — Model\Routes.cs.
13. [ДОБАВЛЕНО 10.11.2026, ПЕРЕДЕЛАНО 10.11.2026] Обозначения светофоров (Model\Naming.cs, окно Ui\NamingForm.cs).
   Имя даётся только НОВОМУ светофору — в момент, когда его поставили; остальные светофоры не переименовываются.
   Буква Н / Ч — от ближайшего светофора с известной буквой: того же направления — та же, встречного — противоположная
   (рядом с Ч→ новый ← будет Н). Светофоров ещё нет — из настройки станции «Движение →».
   Вид «Авто (по участку)» в панели «Светофор» (по умолчанию): путь (1П, 3П, IIП) → выходной; перегон → входной, если впереди
   станция и входного ещё нет, иначе проходной; тупик, стрелочный, участок между светофорами → маневровый.
   Кнопка «Обозначения…» (верхняя панель): «Движение →» — нечётное (Н) / чётное (Ч); шаблоны имён по видам:
     {Б} — буква, {П} — номер пути из названия участка (3, 3П → 3; II, IIП → II), {N} — порядковый номер, {О} — основной впереди.
     По умолчанию: входной {Б} (второй — +Д), выходной {Б}{П}, маршрутный {Б}М{П}, маневровый М{N} (нечётные в горловине
     входного Н, чётные — Ч), проходной {N} (у входного 1 / 2, дальше 3, 5… / 4, 6…), предупредительный и повторительный П{О},
     заградительный З{N}, прикрытия {Б}П{П};
   вид нового светофора по типу участка; «Перенумеровать все…» — по правилам, со списком изменений (отменяется «↶»),
   закреплённые («имя вручную») не трогаются. Имя, вписанное вручную, закрепляется само.
   Если имя запасное (у участка нет номера пути) или уже есть на схеме — пояснение в строке состояния.
   В JSON: станция "rightOdd", "naming": { "templates": {вид: шаблон}, "kindBySec": {тип участка: вид} }; светофор "fixed".
   Вопрос «Перенумеровать?» при открытии старых схем убран; "autoNames" в файлах больше не используется.
   [ДОБАВЛЕНО 10.11.2026] Цифра — от названия пути у всех видов: шаблоны по умолчанию входной {Б}{П} (на перегоне — Н,
   на пути 1П — Н1), маневровый М{П} (на пути 3П — М3, в горловине или если М3 уже есть — порядковый, нечётные у входного Н).
   Светофор помнит, как собрано имя (буква «ltr», своя цифра «num», порядковый номер «seq» в JSON), и имя пересобирается
   само после любого изменения: переименовали путь 3П → 7П — Н3 стал Н7, ПЧ3 стал ПЧ7; поменяли шаблон — тоже.
   Поле «№» у светофора в «Свойствах»: пусто — цифра от пути (подсказка показывает какая), вписали свою — Ч + 5 → Ч5.
   Не меняются сами: «имя вручную» и старые светофоры (без «ltr»); снять «имя вручную» — имя посчитается заново по правилам.
14. [ДОБАВЛЕНО 10.11.2026] Буква нового светофора — прежде всего от входного: есть входной Н → — все новые светофоры →
   (выходные, маршрутные…) тоже Н, встречные — Ч. Входных нет — от ближайшего светофора, как раньше.
   Важно: букву в шаблоне не вписывать жёстко («Ч{П}», «Н») — тогда она одна в обе стороны. Окно «Обозначения…» при «ОК»
   предлагает заменить такую букву на {Б}.
15. [ДОБАВЛЕНО 10.11.2026] Свободный текст (инструмент «Своб. текст», клавиша L) — подпись в любом месте схемы, не по клеткам.

   [{ x, y (клетки, дробные), text, size, bold }]; «Экспорт в C#» — g.Text в точных координатах.
   Надписи в клетках (инструмент «Надпись», T) остались как были.

СОХРАНЕНИЕ В JSON
  «Сохранить» (Ctrl+S) — записывает нарисованную станцию в файл .station.json.
  «Сохранить как…» (Ctrl+Shift+S) — в другой файл. «Открыть…» (Ctrl+O) — загрузить.
  По умолчанию файлы кладутся в папку «Станции» рядом с StationEditor.exe.
  Формат JSON тот же, что у веб-макета, плюс новое:
    tiles    — "x,y" → { t: тип кубика, v: вариант, sec: участок, name: номер стрелки, group: съезд,
                         plus: false (стрелка в минусе), sigs: [{ dir: "R"|"L", kind, name }] }
               kind: entry, exit, route, shunt, block, warning, repeater, barrier, cover, other
    sections — участок → { type: auto|path|plain|line|dead, color: "#rrggbb" }
    texts    — "x,y" → { text, size }
    objects  — "x,y" (левый верхний угол) → { type: ammeter|building|clock, name, w, h, seconds }
  Старые файлы открываются как есть. Веб-макет и прежний C#-редактор раздел objects не знают, а новые виды
  светофоров считают «чужими» — схему с ними лучше править здесь.
  Автосохранение: %LOCALAPPDATA%\StationEditor\autosave.station.json (общее с прежним C#-редактором).

ЧТО УМЕЕТ (как раньше)
- Кубики пути (клавиши 1–7): путь, изгиб, стрелка, пересечение, тупик, выход за край схемы, переезд. R — повернуть.
- Участки кистью (B), стыки рисуются сами; тип участка подбирается по названию (1П, 2-4СП, НАУ, ВТ…).
- Стрелки (номер, съезд — спаренные, положение), светофоры (S).
- Маршруты ищутся автоматически; «Испытание» (M) — задать маршрут, перевести стрелку, занять участок.
- «Проверка»: разрывы, клетки без участка, стрелки без номера, повторы имён светофоров; теперь ещё —
  предупредительный / повторительный без основного впереди, заградительный без переезда.
- «Экспорт в C#» — черновик BuildSections / BuildSwitches / BuildSignals / BuildRoutes / BuildGeometry.
- Отмена / возврат (Ctrl+Z / Ctrl+Y), выделение рамкой и перенос, масштаб колесом. Справка — F1.
