ТЕСТ СВЕТОФОРОВ АКЖТ (отдельно от станции)
==========================================

Зачем: Station включает АВТО зелёные на свободных блоках — на макете кажется
«всё мигает / не то». Тестер гасит всё и жжёт по одной лампе = проверка проводки.

ШАГИ
1. Закрой Station.exe полностью.
2. ПРОШИТЬ_ТЕСТ_СВЕТОФОРОВ.bat  (или IDE → arduino\AKZHT_Lights_Test\AKZHT_Lights_Test.ino)
3. тест_светофоров_АКЖТ.bat → Подключить COM5

В пульте:
  ВСЁ ГАСИТЬ     — темнота (норма «всё закрыто» без красных, если хочешь)
  ВСЁ КРАСНОЕ    — все К по карте Excel
  Обход по битам — по очереди каждый бит 0.0…12.7 (~0,7 с)
  Слева светофор → кнопка лампы → должна загореться ТОЛЬКО она
  ✓ / ✗ — пиши результат → Сохранить чек → python\lights_check.json

Вернуть станцию:
  Залей снова StationMain_AKZHT.ino и запусти Station.exe
