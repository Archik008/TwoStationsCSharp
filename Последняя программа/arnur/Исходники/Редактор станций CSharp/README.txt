РЕДАКТОР СТАНЦИЙ (C#, .NET 8, WinForms) — схема станции из «кубиков»
=====================================================================

Переписан с веб-макета «Исходники\Редактор станций» (HTML/JS) — то же поведение, но обычная программа Windows.

ЗАПУСК
  готовая_программа\Редактор станций\StationEditor.exe   (собирается build_exe.bat, ставить .NET не нужно)
  Можно открыть файл сразу: StationEditor.exe "схема.station.json" (или перетащить файл на exe).

СОХРАНЕНИЕ В JSON
  «Сохранить» (Ctrl+S) — записывает нарисованную станцию в файл .station.json.
  «Сохранить как…» (Ctrl+Shift+S) — в другой файл. «Открыть…» (Ctrl+O) — загрузить.
  По умолчанию файлы кладутся в папку «Станции» рядом с StationEditor.exe (там уже лежат примеры).
  Формат JSON тот же, что у веб-макета: файлы открываются в обеих версиях.
    tiles    — "x,y" → { t: тип кубика, v: вариант, sec: участок, name: номер стрелки, group: съезд,
                         plus: false (стрелка в минусе), sigs: [{ dir: "R"|"L", kind, name }] }
    sections — участок → { type: auto|path|plain|line|dead, color: "#rrggbb" }
    texts    — "x,y" → { text, size }
  Автосохранение: %LOCALAPPDATA%\StationEditor\autosave.station.json — после перезапуска схема откроется снова.
  При закрытии с несохранёнными изменениями программа спросит, сохранить ли файл.

ЧТО УМЕЕТ (как веб-макет)
- Кубики пути (клавиши 1–7): путь, изгиб, стрелка, пересечение, тупик, выход за край схемы, переезд. R — повернуть.
- Участки кистью (B), стыки рисуются сами; тип участка подбирается по названию (1П, 2-4СП, НАУ, ВТ…).
- Стрелки (номер, съезд — спаренные, положение), светофоры (S): входной, выходной, маневровый, проходной, чужой.
- Маршруты ищутся автоматически; «Испытание» (M) — задать маршрут, перевести стрелку, занять участок.
- «Проверка»: разрывы, клетки без участка, стрелки без номера, повторы имён светофоров.
- «Экспорт в C#» — черновик BuildSections / BuildSwitches / BuildSignals / BuildRoutes / BuildGeometry.
- Отмена / возврат (Ctrl+Z / Ctrl+Y), выделение рамкой и перенос, масштаб колесом. Справка — F1.

ФАЙЛЫ
  StationEditor.sln, build_exe.bat
  StationEditor\Model\Station.cs   — формат станции и чтение / запись JSON
  StationEditor\Model\Core.cs      — кубики, как они стыкуются, участки, светофоры
  StationEditor\Model\Routes.cs    — автопоиск маршрутов и проверка схемы
  StationEditor\Model\CsExport.cs  — экспорт в C#
  StationEditor\Model\Examples.cs  — примеры: Алгабас, разъезд
  StationEditor\Ui\Renderer.cs     — рисование схемы (цвета как в Ui\SchemePalette.cs)
  StationEditor\Ui\MainForm*.cs    — окно, мышь, клавиатура, панели, режим испытания

Проверено: на примерах Алгабас и Разъезд маршруты, проверка и экспорт в C# совпадают с веб-макетом
строка в строку (на Алгабасе — те же 8 поездных и 16 маневровых маршрутов).
