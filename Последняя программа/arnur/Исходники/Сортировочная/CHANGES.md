# Версия 1.0 (12.11.2026) — первая версия: сортировочная станция с горкой

Задача: учебная сортировочная станция, где вагоны отцепляются от локомотива и сортируются по путям с горки; светофоры, стрелки, правила работы локомотивов, несколько видов вагонов и локомотивов. Ответы Мади: отдельная программа; студент — дежурный по горке и оператор замедлителей; станция учебная малая; скатывание со скоростью и торможением; два варианта работы с переключением; маршруты отцепов — ГАЦ и ручной; подвижной состав «как в Казахстане»; схема + вид горки сбоку; замедлители — ступени + АРС; языки и ИИ-помощник; время настоящее + ускорение; название — учебная «Сортировочная».

| Что | Как сделано | Файлы |
|---|---|---|
| Станция | Парк приёма П1–П4 → путь надвига → горка (1ТП, стрелка 1, 2ТП-А / 2ТП-Б, стрелки 2–7) → сортировочный парк 1–8 (назначения и нормы) → парк отправления О1–О4; депо, обходной путь, стоянка ТЭМ18. Профиль по нормам проектирования горок (45‰, 14‰, 9‰, 1,5‰, 0,6‰, встречный 2‰) | `Yard/YardLayout.cs` |
| Подвижной состав | Крытый, полувагон, платформа, контейнерная, цистерна, хоппер, рефрижератор, газовая цистерна («Е»), вагон с людьми («Л»); ТЭ33А, KZ8A, ТЭМ18. Гружёные / порожние — разные массы и сопротивление | `Yard/Rolling.cs` |
| Горочный светофор | Зелёный / Ж+З / Жёлтый / Красный / Красный + «Н» — по Инструкции по сигнализации РК, п. 99; повторитель ПГ, маневровые М1–М4 | `Yard/YardSim.cs`, `Ui/YardView.cs` |
