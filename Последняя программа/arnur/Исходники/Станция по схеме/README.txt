СТАНЦИЯ ПО СХЕМЕ (C#, .NET 8, WinForms) — пульт ДСП любой станции из файла редактора станций
=========================================================================================

Одна программа на все станции: открывает файл .station.json, нарисованный в редакторе станций,
и строит по нему станцию — с тем же окном, кнопками и логикой, что у АКЖТ и Алгабаса.

ЗАПУСК
  готовая_программа\Станция по схеме\StationFromJson.exe            (собирается build_exe.bat)
  StationFromJson.exe "схема.station.json"   — сразу эта схема (можно перетащить файл на exe)
  без файла — последняя открытая схема; если её нет — окно выбора (папка «Станции» рядом с программой)
  Кнопка «Схема…» вверху окна — открыть другую станцию.
  Примеры в папке «Станции»: Станция Алгабас, Разъезд, Разъезд Новый (новые элементы).

ЧТО ЕСТЬ (как у Алгабаса — это его общие файлы)
  схема (участки, стрелки, светофоры, номера, подписи), 4 режима интерфейса и «Параметры», маршруты поездные
  и маневровые (клик: светофор начала → конца или путь), зависимости ЭЦ, разделка, виртуальные поезда,
  занятость вручную, пульт ДСП (замыкание стрелок, автодействие, ИР, взрез, ключ-жезл, пригласительные,
  переезд, «Енисей»), однопутный перегон со сменой направления, журналы и бланки, радиосвязь,
  ИИ-помощник (своя база знаний на каждую станцию: Knowledge\<название>), языки ru / kk / en.

КАК СХЕМА ПРЕВРАЩАЕТСЯ В СТАНЦИЮ (Scheme\JsonLayout.cs)
  участок                → участок (тип: путь / участок / перегон / тупик / стрелочный); клетки без участка → «уч1», «уч2»…
  стрелка, съезд         → стрелка (одинаковый «съезд» — переводятся вместе)
  светофор               → входной: Ж З К Ж Б; выходной и маршрутный: Ж З К Б; маневровый: Б С; проходной: Ж З К
                           (автоблокировка: ограждает участок впереди, смотрит на следующий светофор); чужой — светофор соседа
  маршруты               → автопоиск редактора (те же, что показывает «Испытание» и «Экспорт в C#»)
  перегон                → участки «перегон» подряд; если по нему ездят в обе стороны — однопутный (смена направления)
  переезд                → закрыт, пока занят его участок; маршрут через него — с извещением
  выход за край схемы    → кнопка имитации «Поезд слева → / справа ←»
  движение поездов       → по клеткам и положению стрелок (без светофора на границе — только если стрелки дают проехать)

ПОКА НЕ ПЕРЕНОСИТСЯ (сообщение в журнале при открытии схемы)
  предупредительный, повторительный, заградительный светофоры и светофор прикрытия — их нет в ядре станций;
  объекты: вокзал, часы, амперметр; ПНП; макет Arduino; связь с соседними станциями через сервер;
  занятие с программой «Преподаватель» (вход студента, уроки).

ФАЙЛЫ
  StationFromJson\StationFromJson.csproj   — общие файлы Алгабаса (Core, Ui, Ai) и модель Редактора_05_11 подключены
                                             ССЫЛКАМИ: правка там сразу попадает сюда, копий нет
  StationFromJson\Scheme\JsonLayout.cs     — станция из схемы (замена Algabas\AlgabasLayout.cs)
  StationFromJson\Model\ModelHost.cs, RailModel.cs — модель и таймер (без Arduino и сервера)
  StationFromJson\Ui\SchemeStationForm.cs  — главное окно (общее окно Алгабаса + кнопка «Схема…»)
  StationFromJson\Ai\AiProfile.cs          — своё у ИИ-помощника (название станции и примеры — из схемы)
  StationFromJson\Program.cs               — запуск, выбор файла, последняя схема (%LOCALAPPDATA%\StationScheme)
  Станции\                                 — примеры схем (build_exe.bat копирует их, свои файлы не затирает)
  CHANGES.md                               — журнал изменений

КОГДА ПРИДЁТ НОВЫЙ РЕДАКТОР ДРУГА
  Чтение формата — файлы Исходники\Редактор_05_11\StationEditor\Model\*.cs (ссылки в StationFromJson.csproj).
  Если формат JSON поменяется — поправить чтение там (или подключить файлы нового редактора) и JsonLayout.cs.
