2. Build

  • Needed: .NET SDK 8 or newer (SDK 10 builds net8), Go 1.23+ for the server.
  • Each project has a build_exe.bat: a self-contained single-file exe (win-x64) straight into готовая_программа\<folder>. With a parameter (build_exe.bat x) — no pause at the end.
  • Everything: собрать_всё.bat (without Go the server will not build — build the others one by one).
  • Quick compile check: dotnet build Station.csproj -v q -nologo.
  • User files next to the exe (scheme_style.ini, датчики.txt, Arduino) are not overwritten.
  • bat files must be CRLF and UTF-8 (cmd breaks on LF with Cyrillic).

5. Network and lesson protocol

PromServer relays one-off messages {"type":"event","to":…,"data":{…}} (up to 4 MB) without parsing data. Stations and the teacher (station = "teacher") are clients. The lesson protocol is the data.kind field; the full list is in the header of Core/Training.cs:

Teacher → stationStation → teacher
t_hello, t_login, t_session (lesson, student, time, language, timetable), t_time, t_take, t_stop, t_screen (window region), t_input, t_objects, t_fault_add, t_fault_remove, t_lang s_hello, s_login, s_register, s_progress, s_screen, s_objects, s_faults, s_train_event (train graph), s_result (events, action log, faults, ДУ-46, trains, docs — log and form tables, supplied / removed / localDeparted)

Between stations: DispatchMirror — occupancy of shared line sections, neighbour signals, direction change consent, train hand-over (kind = "train" with number and passport: category, index, train list).

Add new messages the same way (t_* / s_*); handlers: Training.OnEvent at the station, Classroom.OnEvent in the teacher program.

7. Layout and Arduino

PC → Arduino, signals:   'L' + N bytes (1 bit = 1 lamp, 0 = ON)
PC → Arduino, switches:  "W <channel> <1|2>\n"   1 = normal, 2 = reverse, PCA9685 channel
Arduino → PC, sensors:   "Data: 1011…\n"  (74HC165, '0' = section OCCUPIED)
Arduino → PC, sensors:   "Occ: 101\n"     (АКЖТ: sensors directly on pins)
  • Алгабас: lamp and switch map — Algabas/AlgabasHardware.cs. Since 22.10.2026 switches are on shield sockets 0–4 (1 → 0, 4/6 → 1 and 2, 8 → 3, 2 → 4); calibration — in the sketch готовая_программа\Алгабас\Arduino\StationMain\Switches.h. Sensors — датчики.txt next to the exe (section = bit number).
  • АКЖТ: firmware готовая_программа\АКЖТ\Arduino\StationMain_AKZHT, notes — ИНСТРУКЦИЯ.txt there; backup of the old firmware — Backup. The sketch was made by the technicians on 27.10.2026 after the Алгабас sketch; servo channels — AkzhtHardware.cs, Post/PostHardware.cs, calibration — Switches.h. Board traffic is written to arduino_diag.log next to the exe.
  • АКЖТ: the signal lamp map follows the pin table (Документы), variant «АКЖТ + intermediate», 13 bytes; built into AkzhtHardware.cs and written to светофоры.txt next to the exe («АКЖТ Н5 жёлтый = 0.6», «ПОСТ 1-I красный = 7.3»), editable without rebuilding. Firmware StationMain_AKZHT (LIGHT_FRAME_BYTES = 13). Wiring check — «Lamps one by one» button (Ui/LampTestForm.cs).
  • Core/ArduinoLink.cs differs between the programs — do not copy it.
  • Without a board everything works: switches move only on screen, trains are virtual.

8. Translation

Strings in the code stay Russian — they are the keys. Translation happens on display: windows, menus, MessageBox, tables translate themselves (Ui/LangUi.cs); own drawing — L.T(text), formats — L.F("…{0}…", …), HTML — L.Html. Data and protocol stay Russian.

  1. Write the interface in Russian, preferably as whole templates ($"Поезд №{n} на {s}", not glued pieces).
  2. python Инструменты\i18n\check.py --todo new.tsv — new strings without translation.
  3. Add Kazakh and English, move them into Инструменты\i18n\strings.tsv (unneeded ones — into skip.txt).
  4. python Инструменты\i18n\check.py --build → dictionaries Lang\Strings.kk.json / en.json in both stations → rebuild.

Kazakh railway terms must be checked by a native speaker: Инструменты\i18n\ПРОВЕРИТЬ_КАЗАХСКИЙ.md.

10. Editing rules

  • Mark changes with // [ДОБАВЛЕНО date, этап N] or [ИЗМЕНЕНО …]; comments and interface are in Russian.
  • Shared files stay identical in both stations (after editing — cp and cmp).
  • Do not change line endings or encoding of files (check CRLF / LF before editing).
  • Every version gets an entry in CHANGES.md of both stations: «What / How / Files» table, «Verified» and «Not verified».
  • Do not break earlier tests; new features come with their own test.
