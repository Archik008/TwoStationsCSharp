2. Сборка

  • Нужно: .NET SDK 8 или новее (SDK 10 собирает net8), для сервера — Go 1.23+.
  • Каждый проект — свой build_exe.bat: self-contained exe (win-x64, один файл) сразу в готовая_программа\<папка>. С параметром (build_exe.bat x) — без паузы в конце.
  • Всё сразу: собрать_всё.bat (без Go сервер не соберётся — остальные соберутся по одному).
  • Быстрая проверка компиляции: dotnet build Station.csproj -v q -nologo.
  • Пользовательские файлы рядом с exe (scheme_style.ini, датчики.txt, Arduino) сборка не затирает.
  • bat-файлы — в CRLF и UTF-8 (с LF и кириллицей cmd ломается).

5. Сеть и протокол занятия

PromServer рассылает разовые сообщения {"type":"event","to":…,"data":{…}} (до 4 МБ), содержимое data не разбирает. Станции и преподаватель (station = "teacher") — клиенты. Протокол занятия — поле data.kind, полный список в шапке Core/Training.cs:

Преподаватель → станцияСтанция → преподаватель
t_hello, t_login, t_session (урок, студент, время, язык, расписание), t_time, t_take, t_stop, t_screen (область окна), t_input, t_objects, t_fault_add, t_fault_remove, t_lang s_hello, s_login, s_register, s_progress, s_screen, s_objects, s_faults, s_train_event (ГИД), s_result (события, журнал действий, неисправности, ДУ-46, поезда, docs — таблицы журналов и бланков, supplied / removed / localDeparted)

Станции между собой: DispatchMirror — занятость общих участков перегона, светофоры соседа, согласие на смену направления, передача поезда (kind = "train" с номером и паспортом: категория, индекс, натурный лист).

Новые сообщения добавляйте по той же схеме (t_* / s_*), приём: на станции — Training.OnEvent, у преподавателя — Classroom.OnEvent.

7. Макет и Arduino

ПК → Arduino, светофоры:  'L' + N байт (1 бит = 1 лампа, 0 = ГОРИТ)
ПК → Arduino, стрелки:    "W <канал> <1|2>\n"   1 = плюс, 2 = минус, канал PCA9685
Arduino → ПК, датчики:    "Data: 1011…\n"  (74HC165, '0' = участок ЗАНЯТ)
Arduino → ПК, датчики:    "Occ: 101\n"     (АКЖТ: датчики прямо на пинах)
  • Алгабас: карта ламп и стрелок — Algabas/AlgabasHardware.cs. С 22.10.2026 стрелки на разъёмах шилда 0–4 (1 → 0, 4/6 → 1 и 2, 8 → 3, 2 → 4); калибровка — в скетче готовая_программа\Алгабас\Arduino\StationMain\Switches.h. Датчики — файл датчики.txt рядом с exe (участок = номер бита).
  • АКЖТ: прошивка готовая_программа\АКЖТ\Arduino\StationMain_AKZHT, пояснения — ИНСТРУКЦИЯ.txt там же; резервная копия старой прошивки — Backup. Скетч сделан наладчиками 27.10.2026 по образцу скетча Алгабаса; каналы серво — AkzhtHardware.cs, Post/PostHardware.cs, калибровка — Switches.h. Обмен с платой пишется в arduino_diag.log рядом с exe.
  • АКЖТ: карта ламп светофоров — по таблице распиновки (Документы), вариант «АКЖТ + промежуточная», 13 байт; встроена в AkzhtHardware.cs и выгружается в файл светофоры.txt рядом с exe (строки «АКЖТ Н5 жёлтый = 0.6», «ПОСТ 1-I красный = 7.3»), правится без пересборки. Прошивка StationMain_AKZHT (LIGHT_FRAME_BYTES = 13). Проверка проводки — кнопка «Лампы по одной» (Ui/LampTestForm.cs).
  • Core/ArduinoLink.cs у программ разный — не копировать между ними.
  • Без платы всё работает: стрелки переводятся только на экране, поезда — виртуальные.

8. Перевод

Строки в коде остаются русскими — это ключи. Перевод — при показе: окна, меню, MessageBox, таблицы переводятся сами (Ui/LangUi.cs), своё рисование — L.T(текст), формат — L.F("…{0}…", …), HTML — L.Html. В данные и протокол — только русский.

  1. Пишите интерфейс по-русски, лучше целыми шаблонами ($"Поезд №{n} на {s}", а не склейкой из кусков).
  2. python Инструменты\i18n\check.py --todo новое.tsv — новые строки без перевода.
  3. Дописать казахский и английский, перенести в Инструменты\i18n\strings.tsv (ненужные — в skip.txt).
  4. python Инструменты\i18n\check.py --build → словари Lang\Strings.kk.json / en.json в обе станции → пересобрать.

Казахские железнодорожные термины нужно проверить носителю: Инструменты\i18n\ПРОВЕРИТЬ_КАЗАХСКИЙ.md.

10. Правила правок

  • Комментарий к правке — // [ДОБАВЛЕНО дата, этап N] или [ИЗМЕНЕНО …]; комментарии и интерфейс — по-русски.
  • Общие файлы — одинаковые в обеих станциях (после правки — cp и cmp).
  • Не менять концы строк и кодировку файлов (смотрите CRLF / LF перед правкой).
  • Каждая версия — запись в CHANGES.md обеих станций: таблица «Что / Как / Файлы», «Проверено» и «Не проверено».
  • Тесты прошлых этапов не ломать; новые функции — со своим тестом.

11. Что не проверено и что дальше

  • Не проверено вживую: клики во всех окнах, работа между несколькими ПК, макет с настоящими датчиками и номерами поездов, звук, два монитора АКЖТ.
  • Казахский перевод терминов — проверка носителем.
  • Отложено заказчиком: программа поездного диспетчера (ДНЦ).
